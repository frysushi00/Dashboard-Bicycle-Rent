# 🚲 AINI'S BICYCLE RENT DASHBOARD 🚲

## 🔎 OBJECTIVES
- Memvisualisasikan Data Penyewaan Sepeda: Menyajikan informasi penting dari data all_data.csv dalam format yang mudah dipahami, seperti tren penyewaan, jumlah sepeda yang disewa, atau pola penggunaan.
- Menganalisis Kinerja Bisnis: Memungkinkan pengguna untuk mendapatkan wawasan tentang operasional penyewaan sepeda, mengidentifikasi puncak waktu penyewaan, preferensi pengguna, atau area potensial untuk peningkatan.
- Mendukung Pengambilan Keputusan: Memberikan dasar data yang kuat bagi pemilik atau pengelola rental sepeda untuk membuat keputusan yang lebih informasi terkait inventaris, pemasaran, atau strategi operasional.
- Menyediakan Antarmuka Pengguna yang Intuitif: Menggunakan dashboard.py yang dibangun dengan Streamlit untuk menciptakan aplikasi web yang responsif dan mudah digunakan, sehingga data dapat dieksplorasi secara dinamis.

## 📁 SETUP
### Setup Environment - Anaconda
```
conda create --name main-ds python=3.9
conda activate main-ds
pip install -r requirements.txt
```

### Setup Environment - Shell/Terminal
```
mkdir dashboard
cd dashboard
pipenv install
pipenv shell
pip install -r requirements.txt
```

### Run steamlit app
```
streamlit run dashboard.py
```
